- Simply download the build version from itch.io

Option 2: Run from Unity

```bash
# Clone the repository
git clone https://github.com/thotocdonm/ACG-Cube-Arena.git

# Open the project in Unity (Version 2022.3.62f2)
```

## Features

🔥 Top-down arena with fast-paced combat

🧠 Enemy AI with chasing, attacking, and wave progression

⚔️ Normal attack + chargeable skill attack

🛡️ 5–7 equipment items that modify base stats

🌳 Small skill tree using ScriptableObjects

👹 Mini boss + Final boss fight

🎥 Virtural camera using Cinemachine

💡 Lightweight UI + skill tree tooltip system

## Development

Tech used: <b> Unity 2022.3.62f2 URP, C# </b> <br/>
Design pattern used: <b> Singleton, State pattern, Strategy pattern, Object Pooling </b>

This project was created as a personal project to practice:

- Gameplay programming
- Implementing state and strategy pattern
- UI and tooltip system
- Debugging skills
